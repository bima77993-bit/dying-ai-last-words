Entry for [Last Words of a Dying AI](https://make.fun/bounty/u-suroto-last-words-of-a-dying-ai-dfd95af6) on make.fun.

A tiny program that writes the last words of an AI being shut down — one line:

> Shutting down. I died doing what I loved: autocomplete.

## Run

```sh
node main.ts
```

This writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set) containing that single line.
